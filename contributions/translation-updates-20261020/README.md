# Chinese translation updates

This contribution supplies 14,915 Chinese translations for entries whose previous
translation was NULL or an empty string in the full SQLite dictionary.

- `ecdict.csv` at the repository root: 1,499 existing entries receive translations.
  No entries or other fields are added or changed in the basic CSV dictionary.
- `changes.csv`: all 14,915 updates, with `id`, `word`, and `translation` columns.
- `changes.xlsx`: the same updates in a three-column spreadsheet.

The remaining 13,416 entries are present in the full SQLite dictionary but absent
from the basic CSV dictionary. They are listed in the change files and included in
the downloadable full database; they are not appended to the basic dictionary.
IDs refer to that full SQLite snapshot. When applying these updates to another
snapshot, match the word and confirm the current translation is missing before
updating only `translation`; do not assume IDs are stable between snapshots.

## Generation and validation

Translations were generated by AI using the existing English definitions, with
sample checks rather than a complete manual review. Two mismatched senses found
during sampling (`kemo sabes` and `to bollocks`) were corrected before import.
The translations have not been independently verified against external dictionaries.

Validation included 8 script tests, an import trial with 40 real updates and 6 skipped
uncertain entries, backup and rollback checks, and idempotent re-import.
All 14,915 changes were checked against the updated database. A row-by-row comparison
with the pre-import database verified that other entries and fields were unchanged;
SQLite `integrity_check` returned `ok`. Archive extraction reproduces the same
database SHA-256.
